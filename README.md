## 🙋‍♂️ 소개

글로벌 서비스 환경에서 다양한 플랫폼 기능을 개발하고,  
운영 중 발생하는 성능 이슈를 구조적으로 해결해 온 백엔드 개발자입니다.

Node.js(NestJS) 기반 실무 경험을 중심으로  
결제, 이벤트, 관리자 시스템, 운영 자동화 등 서비스 전반의 기능을 직접 설계·구현해 왔으며,  
슬로우 쿼리 개선과 API 구조 리팩토링을 통해 실제 서비스 응답 성능과 안정성을 개선한 경험이 있습니다.

프론트엔드(React, Next.js) 경험을 바탕으로  
기획·디자인·프론트엔드와의 협업 과정에서도 전체 흐름을 이해하며 문제를 해결하는 개발을 지향하고,  
최근에는 Spring Boot, Kotlin, AWS 기반 환경까지 확장해 더 큰 규모의 시스템 설계 경험을 쌓고 있습니다.
